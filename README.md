## 关于我

专注于游戏服务端架构、分布式系统与云原生基础设施，致力于通过平台化、基础设施即代码（IaC）和 AI 工具，提升游戏研发效率、系统稳定性与工程质量。

- **游戏服务端架构：** 构建高可用、可扩展的游戏服务器架构，关注高并发网络通信、分布式系统与服务治理。
- **通用平台建设：** 设计标准化、可复用的中台与基础服务，降低业务接入成本，提升多项目间的技术复用能力。
- **云原生游戏基础设施：** 探索基于 Kubernetes 与 Agones 的游戏战斗平台，关注游戏服务器编排、弹性扩缩容、会话调度与高可用治理。
- **基础设施即代码（IaC）：** 探索使用 AWS CDK 与 CloudFormation 管理云资源，推动基础设施配置代码化、环境部署自动化和变更流程标准化。
- **研发效能与 AI：** 探索 AI 在代码开发、自动化测试、故障分析及工程知识沉淀中的应用。

## 正在探索

- **IaC 工程化：** 基于 AWS CDK 将网络、计算、数据库、消息队列和监控等基础设施纳入代码管理，探索可复用的 Stack、环境隔离与自动化部署。
- **云原生战斗平台：** 基于 Kubernetes 与 Agones 探索战斗服生命周期管理、会话分配、弹性扩缩容及故障恢复。
- **多云与平台化：** 研究 AWS 托管服务与云原生开源方案的适用边界，探索国内外环境的部署标准化及云厂商解耦。
- **AI for Engineering：** 探索 AI 在研发工作流、测试自动化、故障定位与技术知识管理中的实际应用。
